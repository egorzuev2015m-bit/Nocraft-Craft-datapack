# Nocraft-Craft-datapack

Это дата пак создан для крафтов предметов которых нельзя скрафтить

## Как им пользоватся

1. Скачай готовый .zip архив в Relese
2. Зайди в майнкрафт  26.2
3. В папке saves выбери нужный мир и положи .zip в папку datapacks или datapack
4. Играй и крафти!

## Какие есть крафты?

Посмотреть крафты можно посмотреть в папке crafts в исходном коде
